# Changelog

Per-version release notes live in **[GitHub Releases](https://github.com/kagura-ai/kagura-memory-python-sdk/releases)** — that is the canonical changelog. The `/release` flow publishes notes there automatically on every tagged version, so this file is intentionally a pointer rather than a hand-maintained list (which would drift out of date).

- **Browse all versions** — <https://github.com/kagura-ai/kagura-memory-python-sdk/releases>
- **Compare two versions** — `https://github.com/kagura-ai/kagura-memory-python-sdk/compare/vX.Y.Z...vA.B.C`
- **Your installed version** — `python -c "import kagura_memory; print(kagura_memory.__version__)"`

> Detailed in-repo notes for **v0.18.0–v0.25.0** remain available in this file's
> git history; every version from **v0.26.0** onward is tracked exclusively in
> GitHub Releases.
